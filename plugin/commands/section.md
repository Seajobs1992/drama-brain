---
description: Drama Brain. Read one section of a document
argument-hint: <doc> <heading>
---
Run this now with the Bash tool. The first word is the document, the rest is the heading, in double quotes:

    /usr/bin/python3 ~/drama-brain/brain.py section <doc> "<heading>"

Document and heading: $ARGUMENTS

To see the documents, run `/usr/bin/python3 ~/drama-brain/brain.py docs`. On Windows use `python %USERPROFILE%\drama-brain\brain.py` instead.
